    Service API keys
    
      
    Tokens for auxiliary features (image generation, wake word). Stored on this device only, shown masked, never returned in full.
    
      
    
      
    

      
    Engine selection
    
      
    Where each model runs. Choices are saved now and take effect as each feature becomes available.
    
      
    
      
    
        
      
    
      
    

      
    On-device model
    
      
    Run chat fully offline on this phone (LiteRT-LM / Gemma). Download once from the catalogue, or use IMPORT FILE to load a .litertlm file you already have (e.g. downloaded via Chrome). Gemma downloads need a free Hugging Face token with the license accepted once (Service API keys above).
    
      
    
      
    
      
    

      
    Voice & wake word
    
      
    Press MIC in chat to speak, SAY to hear the last reply, and say "Jarvis" to wake the app (Android, fully on-device via Picovoice Porcupine - free access key above). Speech engine is chosen under Engine selection.
    
      
    
      
    
        
        
      
    
      
    

      
    WhatsApp
    
      
    Reads WhatsApp messages from notifications (Android, after you grant notification access) and can draft or send replies using each chat's own style. Import an exported chat file to map a full conversation. Replies only go out when auto-reply is on and the chat's rule allows it.
    
      
    
      
    
        
        
      
    
      
    
        
        
        
      
    
      
    
        
        
      
    
      
    
      
    

      
    Device control
    
      
    Let Jarvis read the screen and tap, scroll, type or press back/home through Android's accessibility service. Both halves of consent are yours: grant access in Android Settings, then turn on the master toggle here. Every action that runs is written to the audit log below - nothing runs until both switches are on.
    
      
    
      
    
        
        
      
    
      
    
        
      
    
      
    
      
    

      
    Cross-surface sync
    
      
    Keep chats, notes, tasks and memory in sync across the APK, WebUI and desktop. Every device runs a small sync listener on port 8772 (LAN only, protected by the shared token). Add each other's address as a peer; you can also push a manual backup to GitHub as a fallback.
